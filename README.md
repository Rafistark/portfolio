## ⚡ Quick Test Locally

Double-click **`run.bat`** in this folder (`D:\portfolio\run.bat`).
It will start your local streaming server and automatically open **`http://localhost:3000`** in your default browser.

---

## 🚀 How to Publish to the Internet (100% Free Forever)

### Option 1: Netlify Drop (Fastest & Easiest — 30 Seconds)
1. Open your browser and go to **[app.netlify.com/drop](https://app.netlify.com/drop)**.
2. Sign in or create a free account.
3. Open File Explorer on your computer to **`D:\`**.
4. Drag and drop the **`portfolio`** folder directly into the Netlify Drop box.
5. In 30 seconds, Netlify will give you a live public URL (e.g. `https://muhammed-rafi-edits.netlify.app`) with free HTTPS!
6. You can customize the site name in **Site Configuration > Change site name**.

---

### Option 2: GitHub Pages
1. Go to **[github.com](https://github.com)** and create a new public repository named `portfolio`.
2. Upload the files from `D:\portfolio`.
3. In your repository, go to **Settings > Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your portfolio will be live at `https://<your-username>.github.io/portfolio`.

---

### Option 3: Vercel
1. Go to **[vercel.com](https://vercel.com)** and sign up with GitHub or Google.
2. Click **"Add New Project"** and select your GitHub repository, or deploy via Vercel CLI.
3. Your site will be live instantly with a global fast CDN.
